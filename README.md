# Data Structures and Algorithms (DSA) Practice

Welcome to my repository for practicing and implementing various Data Structures and Algorithms. This collection serves as both a comprehensive guide and a portfolio of my solutions to common DSA problems, primarily in Java (feel free to contribute in other languages).

## Introduction

This repository is dedicated to exploring and mastering fundamental concepts in Data Structures and Algorithms. Each topic has its own folder containing:
- Implementations of core data structures and algorithms
- Solutions to related problems
- (Optional) Explanations and notes

## Topics Covered

- **Linked Lists**  
  Single, Doubly, and Circular Linked Lists; operations and popular problems (reverse, detect cycle, merge, etc.)
- **Arrays**  
  Basic operations, min/max finding, array rotations, two-pointer techniques, etc.
- **Strings**  
  String manipulation, pattern matching, anagrams, palindromes, etc.
- **Trees**  
  Binary Trees (BST, AVL, Red-Black), traversals, LCA, path sum, and more
- **Graphs**  
  Representations, BFS/DFS, shortest path algorithms, MSTs (Prim’s, Kruskal’s)
- **Sorting Algorithms**  
  Bubble, Selection, Insertion, Merge, Quick, Heap Sort, and more
- **Searching Algorithms**  
  Linear and Binary Search
- **Hashing**  
  Hash tables and collision resolution
- **Recursion and Backtracking**  
  Recursive solutions and backtracking problems
- **Dynamic Programming**  
  Classic DP problems and solutions

> _Note: Not all sections are complete yet. I am actively expanding each topic._

## How to Navigate This Repository

Each topic is organized into its own directory. Inside each folder, you will find Java files and, where relevant, additional notes or test cases.

For example:  
- `LinkedLists/` – Implementation and problems for linked lists  
- `Trees/` – Binary tree data structures and algorithms  
- etc.
